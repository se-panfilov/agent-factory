## Implemented behavior (P08 scope)

1. **Added S07 offline verification stage**
   - New `S07` stage in `setup/src/stages/verification.ts`, dependency `S06`.
   - Runs fake-provider verification via reviewed `runner_verify` command from deployment manifest (no OAuth/live call).
   - Persists offline evidence to `s07-offline-verification.json` with strict schema/identity checks.
   - Enforces no-secret Docker boundary probe using pinned S06 image evidence (`s06-agent-image.json`):
     - creates bounded fixture container,
     - inspects mounts,
     - rejects auth/state secret mounts,
     - requires successful cleanup (cleanup failure => exit 8 path).
   - Verifies toy fixture SHA consistency and marks drift when source changed after verification.

2. **Added S08 auth/live smoke stage + explicit command handlers**
   - New `S08` stage in `setup/src/stages/auth.ts`, dependency `S07`.
   - Stage `apply`/`verify` only consumes explicit evidence; it never triggers OAuth/live call itself.
   - Added explicit command handlers:
     - `factory-setup auth login --config PATH`
     - `factory-setup auth status --config PATH`
     - `factory-setup smoke --config PATH --provider fake|live --fixture toy`
   - `auth login` runs pinned image in interactive Docker mode with `/auth` bind mount; no npm/project scripts execution.
   - `auth status` checks **presence only** (`quota_healthy` is always `unknown`).
   - `smoke --provider live` requires:
     - approved risk/quota gates,
     - verified S07,
     - one bounded attempt (300s), no auto-retry,
     - strict result JSON validation, trusted terminal events, and unchanged fixture SHA.
   - Interrupted/unknown live usage is persisted as blocked evidence (`unknown_usage=true`) and does not become verified.

3. **Wired P08 into engine and CLI**
   - Registered new stages in static registry after S06: `S07`, `S08`.
   - Engine command router now supports `auth-login`, `auth-status`, `smoke`.
   - CLI now maps:
     - `auth login` -> `auth-login`
     - `auth status` -> `auth-status`
     - `smoke --provider ... --fixture toy`
   - Help text updated for new explicit commands.
