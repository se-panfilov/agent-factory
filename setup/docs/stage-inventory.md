# Executable stage inventory — Q1A-R1.4

Contract 1.0.0. `plan --stage ID` selects its full dependency closure. Both profiles mean supervised and service; this is code admission, never real-host qualification. Generic apply rejects any plan containing S08 or S14, even when reached through a dependency. No optional route bypasses that guard. All real-host execution below remains NOT RUN.

Core passes exactly one operation to apply; empty/verify-only plans go to verify without apply. Every returned effect receipt must match that exact operation/stage/resource. S02…S05 additionally have explicit operation postcondition callbacks before the verify/checkpoint records.
