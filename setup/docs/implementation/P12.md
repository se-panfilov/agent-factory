## Implemented behavior (P12 scope only)

1. Added **S12 stage** (`optional=true`, dependency on `S09`) with stage lifecycle:
   - observe → plan → apply → verify → recover.
2. Added **pin-validated inference artifact model** (`s12-inference-pins.json`) requiring:
   - immutable image/model digests,
   - model size/license,
   - `num_ctx=8192`,
   - resource floors and runtime identities.
3. Added **resource admission** checks for RAM/disk/inodes with explicit failure codes:
   - 16 GiB default RAM floor for 10g profile,
   - optional stage failure uses exit code 10 path.
4. Added **private compose template** and rendering with:
   - internal network only,
   - no host port publishing,
   - CPU/memory/PIDs limits.
5. Added **S12 health/state artifacts**:
   - `s12-inference-health.json`,
   - `s12-inference-state.json`.
6. Added **integration admission guard**:
   - no routing claims until M3 + PR13/14/15/16/17 evidence exists,
   - otherwise records `routing_enabled=false`.
7. Added **CLI command**:
   - `factory-setup inference disable --config PATH`
   - idempotent disable flow: schedule block hook (if provided) → stop serving → keep model volume/weights.
