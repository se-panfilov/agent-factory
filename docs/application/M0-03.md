## Security-sensitive notes

- Packaging выполняется из конкретного commit через `git ls-tree` + `git show`, без чтения из рабочего дерева для payload.
- Hashes вычисляются программно (SHA-256), вручную не подставляются.
- Offline verification не использует credentials и не запускает сетевые/платные операции.
