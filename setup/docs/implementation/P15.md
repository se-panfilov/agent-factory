## Implemented behavior (P15 scope)

1. Added deterministic release tooling:
   - `release:build` creates a reproducible tarball (`sort/name, owner/group=0, mtime=@0`);
   - emits archive checksum (`.sha256`) and detached signature (`.sig`);
   - writes release manifest with per-file checksums and lock/bootstrap hash references.
2. Added release verification tooling:
   - checksum verification;
   - detached signature verification via OpenSSL;
   - safe tar entry validation (no absolute/traversal paths).
3. Added production lock file `setup/versions.lock.json` with exact pins and source references derived from actual fetched artifacts.
4. Added dedicated VM qualification harness (`setup/tests/vm/`) with explicit owner-consent + disposable-host guardrails; no auto provisioning.
5. Added P15 docs package:
   - quickstart (build/verify/transport/bootstrap/offline/live split),
   - release instructions,
   - qualification status and comprehensive failure matrix,
   - consolidated troubleshooting mapping code → cause → safe action.
6. Added CI setup checks workflow:
   - setup typecheck + tests;
   - dry-run release packaging/sign/verify.
7. Added unit/integration coverage for release manifest schema and packaging/verification scripts.
