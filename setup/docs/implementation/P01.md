## Реализованное поведение

1. **Строгий bootstrap S00 только для owner user**:
   - root запуск запрещён (`exit 3`);
   - host checks: Ubuntu 24.04 + amd64;
   - проверка свободного места и symlink boundaries в install prefixes.
2. **Проверяемый pinned Node install**:
   - manifest `bootstrap-manifest.env` с allowlist keys и строгой валидацией;
   - download Node tarball + SHASUMS + SHASUMS.sig по HTTPS;
   - проверка `gpgv` подписи и exact SHA256/size pin;
   - archive traversal guard, version smoke (`node --version`);
   - атомарная установка в `~/.local/share/agent-factory-setup/node/<exact-version>`.
3. **Idempotency и ownership**:
   - reuse только bootstrap-owned prefix с matching hash/version;
   - unowned/mismatched existing target → drift error (`exit 8`);
   - launcher `~/.local/bin/factory-setup` обновляется только если managed marker.
4. **Минимальный sudo gate для deps**:
   - при missing tools отдельно запрашивается подтверждение;
   - выполняется только минимальный apt install:
     `ca-certificates curl xz-utils gnupg`;
   - нет full-upgrade и нет root-запуска основного CLI.
5. **Receipt**:
   - `~/.local/state/agent-factory-setup/bootstrap-receipt.json`;
   - включает фазовую модель `observe/plan/gated_apply/verify/receipt`;
   - `"installation_complete": false`.

## Покрытые failure/error scenarios (tests + script behavior)

- root execution denied (`exit 3`);
- checksum pin mismatch (`exit 9`);

## Security-sensitive diff

- Запрещены `curl | bash` и `sudo node ...`.
- Download trust основан на reviewed manifest + trusted keyring + signed SHASUMS.
- Symlink/traversal guards для install/archives.
- Cleanup trap удаляет только собственные staging paths; cleanup failure escalates to `exit 8`.
- Secrets не выводятся и не пишутся в receipt/log.
