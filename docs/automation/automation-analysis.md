## Подтверждённое и предположения

Подтверждено чтением (уверенность 99%): документ содержит учебные A1/A2/A3 и DDL, но не поставляемый orchestrator, GitHub publisher, secure broker или local runtime. Наличие кода в Markdown не равно опубликованному tested release. Предыдущие заявления о выполненных тестах сохранены как история автора, здесь они не повторялись.

Проектные решения (уверенность 90% в пригодности, до VM испытаний): единый небольшой CLI, 15 этапов, JSON-state вне SQLite фабрики, user-local pinned Node, minimal Bash bootstrap. Размеры RAM/диска — admission assumptions, а не измерения.

Неизвестно: фактическое состояние приватного repo фабрики, доступность конкретных package/image pins, OAuth аккаунта, производительность VPS. Прямое чтение текущего GitHub anarchy-engine через web не удалось; данные SHA/.nvmrc из исходного guide не выдаются за повторно проверенный HEAD. S09 заново снимает их при deployment.

## Официальные источники, просмотренные повторно 2026-10-21

- Docker Ubuntu: https://docs.docker.com/engine/install/ubuntu/ — signed apt installation и поддержка Ubuntu24.04; точные пакеты нужно квалифицировать в release.
- Docker firewall: https://docs.docker.com/engine/network/packet-filtering-firewalls/ и https://docs.docker.com/engine/network/firewall-nftables/ — native nftables backend имеет отдельные правила; DOCKER-USER нельзя предполагать универсальным. Ubuntu installation page и networking page не полностью согласованы в описании nftables; безопасное решение — явно поддержать iptables backend, не делать миграцию автоматически.
- Node download: https://nodejs.org/en/download — официальные бинарные дистрибутивы и signed SHASUMS. Точная checksum для v24.19.0 через web недоступна; она НЕ выдумана и не включена в design как проверенный pin.
- systemd exec: https://www.freedesktop.org/software/systemd/man/latest/systemd.exec.html — явное окружение службы; конкретные параметры проверить по man установленного Ubuntu systemd, не копировать возможности нового systemd.
- SQLite: https://www.sqlite.org/lang_altertable.html и https://www.sqlite.org/pragma.html — FK переключается вне транзакции; table rebuild внутри; проверки до commit. user_version надо включить в атомарное изменение схемы (вывод аудита).
- Tailscale: https://tailscale.com/docs/how-to/secure-ubuntu-server-with-ufw — доступ через tailnet и закрытие публичного SSH; restore timer и независимая сессия — дополнительные проектные меры.
- Codex: https://learn.chatgpt.com/docs/auth и https://learn.chatgpt.com/docs/non-interactive-mode — device login/exec. Доступность конкретного account и CLI build не проверялась.
- Ollama: https://docs.ollama.com/api/tags — полный digest/size через API; short CLI ID недостаточен как immutable identity.
- GitHub Actions: https://docs.github.com/en/actions/reference/security/secure-use — least privilege и ограничения redaction. Тарифы и план пользователя здесь не перепроверялись, installer не закладывает их как факты.

Ни apt, Docker, OAuth, cloud calls, migrations production, VPS или GitHub writes в Фазе1 не выполнялись. Изменялись только документы в scratch. Проверки этого комплекта: структура файлов, полнота 16 разделов каждого prompt, соответствие stage/PR IDs, ссылки и отсутствие production installation scripts; результаты в phase1-validation.md.
