# M0.1 — Foundation без внешних действий

## Scope

Выполнен только application milestone **M0.1** на ветке `app/m0-01-foundation`:

- TypeScript-домен для оценки результата provider run с инвариантами.
- JSON Schema для четырёх ролей (`scout`, `planner`, `implementer`, `reviewer`).
- Безопасный fake provider fixtures: `success`, `invalid_json`, `missing_result`, `wrong_sha`, `provider_error`.
- Unit tests для инвариантов SHA/structured result и fail-closed поведения.

`setup/` и installer contracts не изменялись.

## Реализованные артефакты

- `src/domain/types.ts` — типы роли, событий провайдера и результата оценки.
- `src/domain/role-result-validator.ts` — Ajv-валидация structured result по role schema + проверка `task_id/input_sha`.
- `src/domain/run-assessor.ts` — детерминированная оценка `needs_review|blocked`:
  - неизвестное событие провайдера не принимается за успех;
  - `turn.failed/error` блокируют run;
  - `exit 0` без валидного `result` не считается успехом.
- `src/domain/application-manifest.ts` — закрытые command keys M0 (`runner_run`, `runner_status`, `runner_stop`, `verify_fake`) по секции application manifest.
- `src/providers/fake/*` — фикстуры и FakeProvider без сетевых/облачных вызовов.
- `schemas/*.json` — четыре role schema c `additionalProperties:false`.
- `prompts/*.txt` — role prompts из guide.
- `tests/run-assessor.test.ts` — 23 unit-теста по acceptance M0.1.
- `package.json`, `tsconfig.json`, `.nvmrc`, `package-lock.json`, обновление `README.md` с командами проверки.
