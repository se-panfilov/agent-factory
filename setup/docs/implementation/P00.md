Дата: 2026-10-21  
Scope: только P00 (`00-contract-and-foundation.md`)

## Изменённые файлы

- `setup/CONTRACT.md` — точная копия `docs/automation/CONTRACT.md` (без изменений содержания).
- `setup/package.json` — отдельный setup-пакет c Node24 target, scripts `build/typecheck/test`, dependency `ajv`.

- `setup/schemas/state.schema.json` — строгая схема состояния C07/C08.
- `setup/schemas/plan.schema.json` — строгая схема планов/операций C06/C10.
- `setup/schemas/installer-release.schema.json` — строгая схема release lock C05.
- `setup/schemas/application-manifest.schema.json` — строгая схема deployment manifest C05.
- `setup/tests/unit/contracts.test.ts` — meaningful unit tests для success+negative fixtures.
- `setup/docs/design-map.md` — map соответствия CONTRACT → артефакты P00.

## Реализованное поведение

1. **Нормативный контракт зафиксирован в setup-пакете**: `setup/CONTRACT.md` синхронизирован с `FACTORY-SETUP-CONTRACT 1.0.0`.
2. **Схемы сделаны строгими**: везде `additionalProperties: false`, обязательные поля, enum/const и pins.
3. **Статические stage/capability identifiers заданы явно**:
   - stage IDs: `S00..S14`,
   - capability names: фиксированный список (без generic/plugin registry).
4. **Валидаторы полностью исполняемые**:
   - schema validation через Ajv Draft 2020,
   - semantic checks для путей (абсолютность, запрет `.`/`..`),
   - единый структурированный результат с перечнем ошибок.
5. **Negative fixtures покрыты тестами**:
   - `schema_unknown`,
   - `unknown_field`,
   - `invalid_path`,
   - `missing_pin`.

## Failure cases / corner cases, покрытые в P00

- Неверная версия схемы (`schema_version != 1`) → reject.
- Лишние поля (`unknown_field`) → reject.
- Невалидный путь (`relative` и path policy failure) → reject.
- Отсутствующий обязательный pin (`codex.integrity`) → reject.

## Security-sensitive changes

- Запрещён policy, допускающий paid fallback (`network.allow_paid_fallback` фиксирован в `false`).
- Путь к секретам и системным артефактам строго в absolute paths; path traversal в конфиге отклоняется.
- Любые unknown config fields отклоняются, чтобы исключить тихие bypass-параметры.
